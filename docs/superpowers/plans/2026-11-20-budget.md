# Budget (VIP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/budget` mockup with a real VIP budget: user-created expense categories, expenses (quantity × unit amount), server-computed totals, CSV export, FR/EN.

**Architecture:** Two new Prisma models + one Ceremony column; a pure domain module (`budget.ts`) for math/seed/CSV; a reusable server tier guard (`tier-guard.ts`); 7 Route Handlers under `app/api/budget/**` following the seating-route pattern; the existing page rewritten as a client component consuming `/api/budget`.

**Tech Stack:** Next.js 16 App Router, Prisma 5 (Neon Postgres, `Prisma.Decimal`), Zod, next-intl, Vitest + `vitest-mock-extended` (`src/test-utils/prisma-mock.ts`).

**Spec:** `docs/superpowers/specs/2026-11-20-budget-design.md`

## Global Constraints

- Every `route.ts` starts with `export const runtime = 'nodejs';` (runtime-enforcement tripwire).
- Mutations: `verifyCsrf(req)` first, then `requireAuth()`, then `requireTier(prisma, userId, 'VIP')`. Reads: `requireAuth()` then `requireTier`.
- Wrap handler bodies in `withRequestContext(makeRequestContext(req.headers), …)`.
- Any ceremony / category / expense not owned by the caller → **404** `{ error: 'CEREMONY_NOT_FOUND' | 'CATEGORY_NOT_FOUND' | 'EXPENSE_NOT_FOUND' }` (never 403).
- Non-VIP → **403** `{ error: 'TIER_REQUIRED', requiredTier: 'VIP' }`.
- **No currency anywhere** (no symbol, no conversion). Amounts are `Prisma.Decimal`, max 2 decimals, never `Float`. JSON responses serialize amounts as strings with 2 decimals (`"1500.00"`).
- Limits: category `label` 1–60 chars; expense `label` 1–120; `planned`/`unitAmount` 0 ≤ x ≤ 999 999 999 999.99; `quantity` 0 < x ≤ 99 999 999.99; `status` ∈ `PAID | PENDING | PLANNED`.
- Spent = PAID + PENDING; upcoming = PLANNED; remaining = totalPlanned − spent; over = spent > planned.
- 6 seed categories, created once per ceremony (guarded by `Ceremony.budgetSeededAt`), in request locale. FR: `Salle & décor`, `Traiteur`, `Tenues`, `Photo & vidéo`, `DJ & musique`, `Divers`. EN: `Venue & decor`, `Catering`, `Outfits`, `Photo & video`, `DJ & music`, `Miscellaneous`.
- Deleting a non-empty category → **409** `{ error: 'CATEGORY_NOT_EMPTY' }`.
- UI: links via `@/i18n/navigation` only; client components use `useTranslations`; `messages/fr.json` and `messages/en.json` get the identical `budget` key shape in the same commit (FR first).
- Before each commit: `pnpm format && pnpm lint && pnpm typecheck && pnpm test` from repo root. Git identity: prefix `GIT_AUTHOR_NAME=Yossafina GIT_AUTHOR_EMAIL=yossafina22@gmail.com GIT_COMMITTER_NAME=Yossafina GIT_COMMITTER_EMAIL=yossafina22@gmail.com` (exported, so it applies to both `git add` and `git commit`). Commit footer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do **not** push without explicit user OK.
- Schema is applied with `pnpm db:push` (VipInvitoz tables are not in `prisma/migrations`); this writes to the user's Neon DB → **ask the user before running it**.

## Review Focus

1. **Decimal sums** — `3 × 0.10` plus `0.20` must total exactly `"0.50"`, not `0.5000000001`. → Task 2 test `sums decimals exactly`.
2. **Cross-ceremony move** — PATCH an expense with a `categoryId` belonging to another ceremony (even the caller's own other ceremony) → 404 `CATEGORY_NOT_FOUND`, row unchanged. → Task 5 test.
3. **Expired VIP** — `tier: 'VIP'` with `expiresAt` in the past or `status: 'EXPIRED'` → 403. → Task 1 test.
4. **Concurrent first open** — two simultaneous first `GET`s must not create 12 categories. Seed claims with `updateMany({ where: { id, budgetSeededAt: null } })` inside the tx and only creates when `count === 1`. → Task 2 test `seed is skipped when claim count is 0`.
5. **CSV formula injection** — a label starting with `=`, `+`, `-`, `@` must be exported prefixed with `'`; `;` and `"` must be quoted/escaped. → Task 2 test `toBudgetCsv neutralises formulas`.

Also pinned: totalPlanned = 0 → `percentSpent` 0 (no NaN) → Task 2.

### Task 2: Budget domain module

**Files:**
- Create: `frontend/src/lib/server/vipinvitoz/budget.ts`
- Test: `frontend/src/lib/server/vipinvitoz/budget.test.ts`

**Interfaces:**
- Consumes: Prisma models from Task 1.
- Produces:
  - `type ExpenseStatus = 'PAID' | 'PENDING' | 'PLANNED'`
  - `const DEFAULT_CATEGORY_LABELS: Record<'fr' | 'en', readonly string[]>` (exact values in Global Constraints)
  - `lineTotal(quantity: Prisma.Decimal, unitAmount: Prisma.Decimal): Prisma.Decimal`
  - `computeBudgetSummary(categories: Pick<BudgetCategory,'id'|'planned'>[], expenses: Pick<BudgetExpense,'categoryId'|'quantity'|'unitAmount'|'status'>[]): BudgetSummary` where `BudgetSummary = { totalPlanned: string; spent: string; upcoming: string; remaining: string; percentSpent: number; over: boolean; byCategory: Record<string, { spent: string; upcoming: string; over: boolean }> }` (strings via `toFixed(2)`, `percentSpent` integer 0–∞, 0 when totalPlanned is 0)
  - `resolveOwnedCeremonyId(prisma, userId: string, requested: string | null): Promise<{ ceremonyId: string | null; notFound: boolean }>` — requested id must match `{ id, userId }` else `notFound: true`; null → most recent `DRAFT|ACTIVE` by `updatedAt desc`.
  - `seedBudgetIfNeeded(prisma, ceremonyId: string, locale: 'fr' | 'en'): Promise<void>` — in `$transaction`: `ceremony.updateMany({ where:{ id, budgetSeededAt:null }, data:{ budgetSeededAt: new Date() } })`; if `count === 1` → `budgetCategory.createMany` with the 6 labels, `order` 0–5, `planned` 0.
  - `findOwnedCategory(prisma, userId, categoryId)` / `findOwnedExpense(prisma, userId, expenseId)` → row or null (filter through `ceremony: { userId }`).
  - `toBudgetCsv(rows: { date: Date | null; category: string; label: string; quantity: string; unitAmount: string; total: string; status: ExpenseStatus }[], headers: readonly string[]): string` — `;` separator, CRLF, leading BOM `﻿`, fields quoted when containing `;` `"` or newline (`"` doubled), labels starting with `= + - @` prefixed with `'`, date `YYYY-MM-DD` or empty.

- [ ] **Step 1: Write failing tests**:
  - `sums decimals exactly`: expenses `{q:3,u:'0.10',PAID}` + `{q:1,u:'0.20',PENDING}` → `spent === '0.50'`
  - `planned is upcoming, not spent`: one PLANNED 100 → `spent '0.00'`, `upcoming '100.00'`
  - `over budget`: planned 100, PAID 150 → `over true`, `remaining '-50.00'`, `percentSpent 150`, `byCategory[id].over true`
  - `zero planned gives 0 percent`: no categories, PAID 10 → `percentSpent 0`
  - `seeds 6 categories in English once`: `updateMany` → `{count:1}` → `createMany` called with labels `DEFAULT_CATEGORY_LABELS.en`
  - `seed is skipped when claim count is 0`: `{count:0}` → `createMany` not called
  - `resolveOwnedCeremonyId returns notFound for a foreign id`: `findFirst` → null → `{ ceremonyId:null, notFound:true }`
  - `toBudgetCsv neutralises formulas`: label `=SUM(A1)` → cell `'=SUM(A1)`; label `a;b"c` → `"a;b""c"`; output starts with `﻿`
- [ ] **Step 2: Run** `pnpm --filter frontend exec vitest run src/lib/server/vipinvitoz/budget.test.ts` → FAIL.
